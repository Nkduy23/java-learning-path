# ☕ Java Learning Path — From Zero to Hero

> Lộ trình học Java thực chiến qua 5 project từ đơn giản đến nâng cao.
> Mỗi project xây dựng trên nền tảng của project trước — không học chay, học bằng cách **làm thật**.

---

## 📁 Cấu trúc thư mục

```
java-learning-path/
├── README.md                        ← File này
├── docs/
│   ├── PLAN.md                      ← Kế hoạch tổng thể
│   ├── JAVA_CHEATSHEET.md           ← Tổng hợp syntax cần nhớ
│   └── GIT_WORKFLOW.md              ← Hướng dẫn push GitHub
├── project-01-calculator/           ← Syntax, biến, hàm, vòng lặp
├── project-02-student-manager/      ← OOP, Class, ArrayList
├── project-03-bank-system/          ← Inheritance, Interface, Exception
├── project-04-library-manager/      ← Collections, File I/O, Design Pattern
└── project-05-ecommerce-api/        ← Spring Boot, REST API, Database
```
